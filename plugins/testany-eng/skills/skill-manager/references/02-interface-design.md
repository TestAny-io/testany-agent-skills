## 信息架构与布局

应用壳包含品牌、导航、环境选择和主内容。五个页面：技能库、插件、市场来源、更新、操作记录。全局本机/演练选择器始终可见，演练有琥珀色标签；环境切换清空搜索以外的详情、安装预览与选择，避免跨环境误操作。

1440px：左侧 212px 导航，主内容最大宽 1280px；技能详情以右侧 400px 抽屉展示。720px：紧凑图标导航或顶部导航，技能单列/列表，详情覆盖内容区域，所有主要按钮仍可见。小屏 390px：顶部品牌与环境选择、横向导航、单列卡片；无强制桌面最小宽。

技能库初始可直接使用：标题「技能库」、说明「在一个地方，整理你的 Codex 能力。」、刷新与「安装技能」；下方四个可点击统计项（全部、已启用、独立技能、需要关注），再是搜索框、来源筛选、网格/列表切换和结果数量。

## 视觉系统

- 暖白画布 `#f6f7f5`，白色卡片，近黑 `#202621` 主文案，灰绿 `#718077` 次文案；橘红 `#e46e43` 作为主要动作和选中点缀，深森林绿用于应用品牌和健康状态。
- 左侧白色/极浅灰底，细分隔线；品牌使用自绘几何 dock 图标。不要依赖网络字体或远程图片。
- 字体使用系统 sans-serif（中文 PingFang SC/Microsoft YaHei）；标题 28px/600，正文 14px，辅助 12px；正文对比度目标 4.5:1。
- 空间采用 4/8px 基准，内容 28px 内边距，卡片 18–22px，圆角 12–16px；阴影仅用于浮层和轻度卡片悬停，避免全屏重阴影。
- 图标采用一致的线性图标集。状态除颜色外有标签文字；危险动作使用红色文字，正常启禁用 switch。
- 动效 120–180ms，尊重 prefers-reduced-motion；搜索不阻塞输入。

## 页面与交互映射

| 页面/组件 | 内容与操作 | Journey/需求 |
|---|---|---|
| 技能卡片/列表 | 图标、名称、用途、来源徽章、启用状态；点击打开详情；开关单独操作不触发打开 | J1 / 001、002、003 |
| 技能详情抽屉 | 来源、完整路径、状态证据、所属插件、重复提示、纯文本 SKILL.md；启禁、检查更新、移除 | J1、J3、J4 / 001、003、005、007 |
| 安装对话框 | 选择本地/Git，输入来源和可选子路径/ref，预览名称用途及目标，再执行安装 | J2 / 004 |
| 插件页 | 安装与可安装筛选、市场、版本、附带技能数、能力标签、启禁/安装/卸载 | J5 / 006 |
| 市场页 | 来源卡片、类型/分支/同步时间、插件数量；添加来源、刷新、移除；可转到该市场插件 | J5 / 006 |
| 更新页 | 受追踪技能、检查状态、变更文件预览、更新按钮；未追踪来源有解释与来源引导 | J3 / 007 |
| 操作记录 | 时间线、动作、对象、成功/失败、结果；可恢复操作显示恢复入口 | J4 / 008 |

## 关键状态

| 状态 | 界面反馈 | 恢复 |
|---|---|---|
| 初次读取 | 骨架屏与正在读取提示，不显示伪造的统计 | 等待；失败后重试 |
| 没有技能/筛选无结果 | 两种不同空态；无技能引导安装，筛选空提供清除条件 | 安装/清除筛选 |
| 单来源失败 | 保留其余结果，顶部非阻断提示和失败来源 | 刷新 |
| CLI 不可用 | 市场/插件页展示不可用原因；独立 skills 操作继续可用 | 设置二进制或按说明修复后重启 |
| 状态未核实/系统/缓存 | 明确徽章；不提供会误导的可写开关，解释原因 | 对所属包或正确安装来源操作 |
| 正在写入 | 对象级/对话框忙碌，阻止重复提交 | 完成后刷新；失败可重试 |
| 内容冲突 | 展示外部变化或目标被占用，保留原始文件 | 重新预览或选择不同目标 |
| 写入成功 | toast、清单即时读回、活动记录；必要时提示新会话生效 | 继续使用 |
| 删除 | 对话框展示目标和影响；独立技能说明可恢复，插件列出附带技能 | 取消/继续；完成后到记录恢复 |

## 可访问性与实用性

按钮均有文字或 aria-label；搜索/路径/ref 输入有 label；开关有 skill 名；Esc 关闭浮层，打开后焦点进入浮层、关闭后返回触发控件；主要通知使用 aria-live。路径自动换行并提供复制。Markdown 作为纯文本显示，避免外来 HTML。批量风险不靠颜色表达。页面状态保留在内存，不把凭证放浏览器存储。

## 实现与验收约束

演练数据来自隔离的真实文件/配置操作，不是按钮只改前端假状态。本机模式展示实际扫描结果。视觉验收至少包含 1440px、720px、390px，以及技能详情、安装、市场、更新、记录与错误恢复。截图、实测结果和缺陷修复记录放入验证报告，不预填通过。
