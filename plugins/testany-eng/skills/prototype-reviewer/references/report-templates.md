# 审查报告与准出证书模板

每份报告和准出证书必须绑定对象/版本、范围、标准、模式（initial/delta/closeout）、已审/未审覆盖及真实证据。沿用稳定问题 ID，分列 kind（defect/evidence_gap/scope_decision/optional）、严重级别和准出影响。通过须无未关闭 P0/P1 且必要证据充分，P2 不按数量阻断。详见 [评审规则](../../../references/review-assurance.md)。

本文档定义 prototype-reviewer 的输出格式模板。

---

## 审查报告（不通过或待补证据）

```markdown
# 原型审查报告

- 评审绑定：[对象/版本/可得摘要；范围；标准/版本；initial/delta/closeout]
- 覆盖状态：[已审；未审；复用证据及有效性]
- 准出影响：[defect / evidence_gap / scope_decision / optional；稳定 ID 与关闭证据]

## 基本信息

| 项目 | 内容 |
|------|------|
| 沙箱目录 | [路径] |
| PRD 来源 | [路径] |
| User Journey 来源 | [路径] |
| 交付摘要 | [路径 / 未提供（evidence_gap，注明所限结论；专项检查不扩大范围）] |
| Visual Brief | [位置、保真度、视觉依据与目标视口/主题] |
| 变更基线 | [commit range / worktree + 归属确认] |
| 审查时间 | YYYY-MM-DD |
| 审查轮次 | 第 N 轮 |
| 审查结论 | [不通过 / 待补证据，未准出 / 专项结论，不授予全量准出] |

## 门一：上游对齐

### 需求覆盖表

| REQ-* | 需求描述 | Manifest 页面 | Journey 步骤 | 状态 | 说明 |
|-------|---------|-------------|-------------|------|------|
| REQ-01 | [描述] | [页面名] | [S1/S2] | ✅/⚠️/❌ | [未覆盖/部分覆盖原因] |

- Journey 步骤覆盖率：X / Y (Z%)
- 门一结论：[实际检查结果 / 证据缺口及未审范围]；本门受阻不取消独立检查，专项隔离检查不强制补做门四。

## 门二：原型体验与完整性

- P0 Journey Happy Path 可达性：[实测全通 / 断点列表 / 未验证及原因]
- 状态矩阵覆盖率：已覆盖 M / 总数 T (Z%)
- 导航完整性：[实测全通 / 缺失列表 / 未验证及原因]
- 视觉品质：[对照 Brief 的层级、排版、颜色、密度、细节、跨页/状态一致性与适配]
- 可用性：[键盘/焦点/对比/表单/恢复等适用项的实际结果]
- 证据覆盖：[当前实现绑定；已看截图与已执行动作；可靠复用依据；未审范围]

| 证据 ID | 页面/状态/视口 | 截图或运行记录 | 观察/操作及预期 → 实际 | 来源与有效性 | 问题/复验 |
|---|---|---|---|---|---|
| EV-01 | [路由、状态、宽×高/主题] | [真实路径] | [具体观察与结果] | [独立实测/可靠复用；对应实现] | [稳定 ID / 无；复验结果] |

> 截图不能代替操作验证，代码检查不能代替视觉观察；证据不可得记 evidence_gap，不自动定产品 P1。

## 门三：工程隔离

| 检查项 | 结果 |
|--------|------|
| 所有原型文件在沙箱内 | ✅/❌ |
| 变更基线已确定 | ✅ [commit range] / ✅ [归属确认] |
| 沙箱外零未授权变更 | ✅/❌ |
| 受控例外已记录 | ✅/❌/N/A |
| 原型路由在专属前缀下 | ✅/❌ |
| package.json 未修改 | ✅/❌ |
| 生产组件/页面/路由未修改 | ✅/❌ |

## 门四：下游可用性

- API Contract 输入评估：[具体 / 笼统 / 缺失]
- HLD 输入评估：[具体 / 笼统 / 缺失]
- 交付摘要与实际一致性：[一致 / 偏差]

## 问题清单

| ID | kind | 级别 | 门 | 问题与影响 | 证据位置 | 修正建议 | 状态与关闭证据 |
|---|---|---|---|---|---|---|---|
| VIS-01 | [defect/evidence_gap/scope_decision/optional] | [P0/P1/P2/不适用] | Gate 2 | [具体影响] | [路由/视口/EV-* 或 文件:行号] | [最小修正] | [open/closed；依据] |

## 放行决策

| P0 | P1 | P2 | 结论 |
|----|----|----|----|
| X 个 | Y 个 | Z 个 | [不通过 / 待补证据，未准出；必要证据/范围决策状态] |

## 下一步

1. [按优先级列出需修复的问题]
2. 修复完成后执行 `/testany-eng:prototype-reviewer` 复审
```
