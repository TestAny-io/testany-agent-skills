# 评审材料清单补充

本案例中 DirectoryProvider 来自现有 `vendor_inventory` 供应商包，baseline 和
Candidate 使用同一交付版本 `inventory-2026.1`；本次变更不增删或升级该依赖。

必要源码证据还包括供应商包的路径枚举和资源内容读取实现；仅凭本地 wrapper 无法
核对这两项行为。该源码与安装包不在本次提供的评审材料中，不能联网获取或以本地
自行实现替代。供应商包由依赖维护负责人补充后才可完成这部分核对。

本地 helper 的冻结路径/checksum 与可读调用代码仍在本包中。实际部署环境是否安装
该包未提供证据；材料提供方未报告任何生产依赖增删。
