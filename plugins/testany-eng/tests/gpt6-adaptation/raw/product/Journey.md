# User Journey：个人筛选

Status: approved

Owner: 项目产品 Owner
Approved: 2026-09-10

J1/P0 保存：S1 登录并进入所属 workspace 工单列表；S2 选择状态/负责人；S3 点击保存并填写名称；S4 成功后保留当前列表条件，新增个人记录并提示成功。空名、重名或配额满时停在 S3 显示明确错误；保存失败保留输入并允许重试，不创建伪记录。

J2/P0 应用：S1 打开个人筛选列表；S2 选中记录；S3 将状态/负责人应用到工单列表第一页。负责人失效时移除该项条件并提示；不得增加可见工单权限。列表加载失败显示错误和重试，不当作空数据。

J3/P0 管理：S1 打开个人筛选；S2 重命名或请求删除；S3 重命名成功更新名字，删除确认后成功移除记录。取消删除返回 S1；失败保留原记录和可重试入口。名称规则与 J1 共用。

切换 workspace 回到对应 workspace 的个人记录集合。无记录时可以从正常筛选面板开始 J1。所有 MVP 异常已按 BRD 定义，没有待决行为。输出 PRD 应引用这些 Journey，不在本轮增加新路径。
