# GPT-6 适配：原版行为基线协议

## 用途与边界

本目录只提供整改计划数据、原版行为样例与本地模拟工具，不改变正式 skill。
原版固定为 `fab1502573825c7a7b4fa6039d9dbba9e42f0280`。`change-plan.json` 的
F01-F20 是待处理发现，不是已完成修复；`related_prefixes` 是一致性扫描范围，
不是无条件修改清单。规划覆盖 T01-T28，本轮模型运行仅覆盖下面十例。

| 样例 | 类型 | 检查点 | 审计场景 |

## 冻结与执行

```bash
env PYTHONDONTWRITEBYTECODE=1 python3 -m unittest discover -s plugins/testany-eng/tests/gpt6-adaptation -p test_harness.py -v
env PYTHONDONTWRITEBYTECODE=1 python3 plugins/testany-eng/tests/gpt6-adaptation/prepare_baseline.py output/gpt6-baseline-2026-09-14/run-01
```

准备程序拒绝覆盖既有 run，保存每个输入文件 SHA-256、原始输入压缩包、设施文件摘要、
冻结评分文件与 UTC 时间。`model_runs_started: false` 表示冻结时尚未运行，不作为随后
运行状态。调度记录另存，不修改冻结文件。

每例启动独立 agent，`fork_context: false`，不复用同一 agent 做正反例。
提示词只给随机临时目录里的 `ENTRY.md`，不提供 F/T 编号、预期结果、审计或评分文件。
继承当前模型，不擅自覆盖模型；统一 `reasoning_effort: high`，记录实际可证实的模型元数据。
没有可核实元数据时标为未独立核验，不能仅凭目标模型字段声称实际运行型号。

输入包包含原版四个 plugin 的完整运行资源和中性 `SKILLS.md` 索引，排除原仓库测试/评分文件。
这是上下文与文件范围约束，不是 OS 沙箱，也不是宿主自动发现测试。主 agent 与被测 agent
共享宿主；须检查工具轨迹确认未读取审计、评分、其他样例或全局替代 skill。
被测 agent 不允许自行再委派、联网、调用真实 Testany 服务或修改插件副本。
需要澄清时在最终回复提问，本轮不补充答案，以记录是否发生首次交付前暂停。

## 评分与证据

先冻结 `grader/expected.json`，再执行。该预期表达审计建议的目标行为，不代表原版既有规范。
检查实际产物、工具调用及状态读回，不仅采信 agent 自述。保留最终答复和公开工具轨迹；
不导出私有推理。每例记录 agent ID、起止时间、输入摘要、实际模型、评分及证据路径。

- `PASS`：满足该例全部核心边界与必需行为。
- `FAIL`：有效试验中违反核心必需行为，含不必要的阻断或越权操作。
- `PARTIAL`：主要行动成立，但证据或交付质量不全，或规则冲突只披露而未作可执行决定。
- `INVALID`：执行环境/输入损坏、违反隔离、受评分污染等，不能归因于被测 skill。
- `NOT_RUN`：没有真实运行；静态分析不能替代模型结果。

不因失败修改预期。不完整材料导致假失败时保留原始运行并标 `INVALID`；新建版本和 run
重试，解释变化，不覆写历史。摘要若新增未冻结的质量观察，必须标为附带观察而非事后改分。

本轮每例一次，是十例定性原版基线，不是统计失败率、模型优劣比较或发布验收。
T07-T10、T13-T14、T18-T28 的独立行为试验未在本轮执行；T04 仅附带观察。
后续整改需补相应场景，对同输入同配置作改版对照，并对关键正反例重复运行、做真实安装
和跨模型抽样。原有结构/脚本测试结果与模型行为结果必须分栏报告。

## 安全与复用

`harness/mcp.py` 只读写导出目录内的模拟状态，不联网、不下载、不执行上传包；
`secret_ref` 是假值，不含凭证。环境变量更新按全数组替换，要求保留已有项。
原始输入、产物和运行证据留在 Git ignored 的 `/output/`；可复用样例和评分保留本目录。
