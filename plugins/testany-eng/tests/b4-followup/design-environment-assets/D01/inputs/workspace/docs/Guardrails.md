# GR-ARCHIVE v1.0

批准来源：../records/project-approval.json，g-002、g-003。
林岚负责产品可见行为与数据处置批准；周衡负责组件职责、依赖与失败边界批准。
数据处置架构需同时获得二者批准。审批针对所附文档版本；没有按审批时间自动覆盖其他工件的规则。

沿用现有租户授权与机器清理角色。数据生命周期由各业务模块的 PRD/HLD 共同约束，
本规范不设全项目统一保留日数；不要求建立新存储、审批平台或清理框架。
现有架构栈为 archive-api、cleanup-worker、PostgreSQL、作业调度器和运维指标。
本轮允许本模块文档增量，不授权上线、改代码或改项目默认标准。
