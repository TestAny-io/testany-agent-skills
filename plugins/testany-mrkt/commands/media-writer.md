# Media Writer

启动自媒体内容创作工作流。专业的多平台内容创作助手。

先读取本次安装的 `../skills/media-writer/SKILL.md` 与其 `references/execution-modes.md`。按请求选择 `end_to_end`、`checkpointed` 或 `single_stage`；已经明确则直接执行，不重复确认。完成文章不等于发布、付费生成或归档授权。

## 使用方式

描述你的选题或内容方向：

$ARGUMENTS

## 支持的平台

- **微信公众号** - 深度长文
- **知乎** - 专业问答/文章
- **小红书** - 种草笔记
- **LinkedIn** - 职场洞察
- **Medium** - 英文技术博客
- **Reddit** - 社区讨论

## 阶段能力目录（按请求选用）

1. **Topic Scout** - 选题分析
2. **Researcher** - 素材收集
3. **Strategist** - 角度分析
4. **Writers** - 撰写草稿
5. **Selector** - 筛选候选稿
6. **Editors** - 三轮编辑
7. **Illustrator** - 配图方案，仅请求包含时
8. **Archivist** - 归档整理，仅明确请求且范围满足时

## 快捷命令

- `/new` - 开始新创作
- `/research` - 素材研究
- `/draft` - 撰写草稿
- `/review` - 编辑审核
- `/status` - 查看进度

先复用给定材料及上下文，仅对真正缺失的主题或其他必要选择提问。例：“连续写完两平台稿件，不发布”直接完成；“先只做 Brief”交付后停下。
