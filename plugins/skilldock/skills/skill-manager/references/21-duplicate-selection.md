# 使用反馈：按安装位置处理同名技能

## 需求与界面（2026-09-15）

同名提示必须提供可操作清单。技能卡片及详情中的“管理同名技能”打开整个同名组，逐份显示完整路径、来源、启用状态与可移除范围。默认全部保留，用户可选择一份或多份移除；“保留”表示不改变文件和启用配置，不隐含启用。按路径区分，不把名称当作删除键。

选择后先展示将移除和将保留的具体路径，确认后移至可恢复区。操作记录按每份路径保存，支持单独恢复。插件附带、系统及尚未核实的缓存沿用现有保护边界，并在对应行说明原因；不能将一次技能选择悄悄扩大为整包卸载。插件项提供所属插件入口。路径别名作为同一份内容的补充信息显示，不伪装成额外安装副本。

## 工程设计

新增只读 `skill.previewRemoval`（groupName、明确 ids）及 `skill.removeSelected`（previewId）。预览从最新扫描绑定整个同名组、选择项的逻辑路径、目录身份、父目录及内容指纹，三十分钟失效且限制在当前环境。提交前整体预检，逐个移动前再次验证；组成员、位置或内容变化即拒绝旧预览。不会按名称执行批量删除。

批量移动沿用受管目录、保护路径及 quarantine 机制。每份生成独立恢复记录和来源元数据备份；中途或持久化失败时回滚已移动对象，回滚失败必须报告。仅删除选中对象的来源记录；未选择项的文件、配置与来源保持不变。单份旧移除入口与恢复保持兼容，恢复界面补充实际路径。

## 验证计划

使用隔离个人/项目目录与插件/系统夹具验证：单选、多选、保留一份/多份、全部取消、取消预览、逐份恢复、同名组变化、内容或目录替换、过期/跨环境预览、受保护项混入请求、移动失败与写状态失败的回滚、符号链接仅移动链接。浏览器覆盖中英日、深浅色与窄屏，核对选择、两步确认、保留项文件和状态不变、恢复目标路径可区分。

## 执行结果（2026-09-15）

- 后端新增 16 项（含参数化子用例）通过，全量 **109/109** 通过。实测移除一份、移除多份、保留一份或多份个人/项目副本；未选择的插件与系统项、来源记录和配置原样保留。恢复其中一份后，其他已移除副本仍保持移除状态。
- 内容修改、同名组新增成员、相同内容但目录 inode 被替换、过期、跨环境和项目切换均拒绝旧预览。混入受保护或无关对象时没有任何移除；模拟第二次移动失败与状态落盘失败，均恢复先前移动的对象及来源记录。
- 符号链接用例确认仅移动所选链接，实际内容与其他副本保留，并能恢复链接。所选实际目录嵌套其他已发现技能时拒绝操作，避免扩大移除范围。
- 新增 7 个浏览器场景通过，全量 **63/63** 通过。三语言分别覆盖浅色 1440px 与深色 390px；取消、全部保留、单选/多选、返回修改选择、两步确认、变更后可见报错、按明确路径单独恢复均已实际执行，并从磁盘核对文件与禁用状态。
- 人工查看深浅色、日语窄屏及确认页截图。长清单只滚动内容区，标题、选中数量与操作按钮保持可见；进入确认页回到清单顶部。
- TypeScript 与 Vite 生产构建通过。没有新增运行时依赖。首次浏览器尝试使用了上一版 dist，因此找不到新入口；重新构建后新增场景和完整回归均通过，原始日志保留。

证据在忽略目录 `output/skilldock-duplicate-selection/`，包含日志、截图、源码归档一致性和最终验证清单。修改保留在 `feature/skilldock-seed-feedback` 候选分支，版本仍为本次待发布的 0.2.0；未提交、推送、发布或替换用户本机插件和 4771 服务。

当前范围：个人/项目技能按路径可恢复移除；插件附带、系统及未核实缓存显示明确限制，不提供伪装成单技能操作的整包卸载。保留表示文件及启用状态保持原样。工程测试通过不代表用户 UAT 已批准。
