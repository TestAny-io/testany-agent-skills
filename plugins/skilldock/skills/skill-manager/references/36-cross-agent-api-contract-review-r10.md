  - 有效依据：7.1 第 224 行“启用计划时每个目标都须可检查，否则整体拒绝”（沿用 0.10.2 `scheduler.mjs` 第 96～101 行）；HLD 3.6 第 668 行（停用管理时目标暂停、不删除）、3.8 第 734 行（暂停的目标不计为失败）；PRD MR-SDX-001。
