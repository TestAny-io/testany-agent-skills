# 更新进度与本机标签

状态：SkillDock 0.3.0 发布基线。用户于 2026-09-15 授权提交、推送并通过 PR 合并到 main；工程验证与用户具体 UAT 结果分别记录。基于已发布 SkillDock 0.2.0，不改变插件发现和更新权限边界。

## 产品需求

- PT-01：点击“检查全部”立即显示准备状态。后台确定目标后显示真实已完成/总数、百分比、当前对象、检查/应用阶段和耗时；完成、部分完成、失败分别反馈。刷新页面或离开后返回可继续看到后台进度。计数按更新对象，一个插件及其附带技能算一个对象；不虚构下载百分比或剩余时间。
- PT-02：插件支持按包更新，包内技能一起更新。插件卡片提供更新入口，跳转到更新页并精确定位所属插件；独立同名副本不随该包更新。仍保留已核实来源、宿主管理和本地修改等既有约束。
- PT-03：每份技能和每个插件可以新增、修改、移除自己的标签。标签为本机元数据，不写 SKILL.md、插件缓存、远程来源或 Codex 配置；不改变技能启禁或包权限。默认不继承插件标签到包内技能。
- PT-04：技能页和插件页均支持标签筛选，能与搜索、来源/市场及状态组合；多选匹配任一选中标签，支持“未添加标签”和清空筛选。刷新、服务重启和正常升级后保留标签；同名不同路径分别维护。

## 界面设计

- 更新页“检查全部”下方放进度卡：标题和百分比、进度条、已完成数量、当前对象、耗时、各结果计数。开始和整理结果阶段明确标注；失败说明保留在现有更新记录中。读进度失败显示重连说明，不能显示为完成。
- 卡片内容与操作区之间展示标签胶囊和编辑入口；无标签时显示“添加标签”。技能详情也能编辑标签。
- 标签弹窗展示可编辑胶囊、单个标签输入框和已有标签建议；输入 Enter 添加/修改，保存才写入，取消保留原值。每个对象最多 12 个标签，每个标签最多 32 个 Unicode 字符；去除首尾空白、合并空白、大小写不敏感去重。
- 筛选控件为可展开、可搜索的多选列表，显示每个标签对应数量；已选标签在工具栏可见。中/英/日及浅/深色、390px 面板均覆盖，控件提供键盘和读屏名称。

## 工程设计

- `GET /api/updates/progress?mode=...` 读取调度器内存中的最新批次摘要，不扫描磁盘、不调用 CLI。复用同源 Host/Origin 校验与 mode 边界。前端活动批次约 750ms 轮询，空闲约 4s；单次请求超时、无并发堆积、卸载取消请求，完成后刷新清单。
- 调度器在初次清单扫描前建立 preparing 记录；确定并去重目标后保存 total。每个对象检查/应用前更新 current，完成后增加结果；最终持久化期间显示 finalizing。旧记录没有 total 仍可读取；启动中断明确转为 error。
- `tags.set` action 接收已发现的 skill/plugin target 和完整 tags 数组，复用已有 token、白名单验证、写互斥、原子 registry 持久化及失败回滚。缺省旧 registry.tags 为无标签。
- 插件标签以插件 ID 为键；已核实包内技能以插件 ID + 包内相对文件路径为键，跨版本缓存路径变化仍保留。个人/项目/系统/未核实缓存技能按现有路径 ID 分开。来源/包内路径或安装位置真正改变时不自动猜测标签归属。
- 标签仅为独立标注；插件更新流程原样保留。共享 wire 契约以 `shared/contracts.ts` 为准。

## 验证计划与 UAT

- 后端：延迟来源期间仍能快速读取进度；准备、逐项、应用、终态计数及中断恢复；重复启动互斥、模式隔离和非法访问。失败/跳过计入已处理，但不误报成功。
- 标签：旧数据兼容、跨服务重启、更新/移除恢复保留、插件版本路径变化、同名区分、受保护对象只标注不修改内容；畸形输入、长度、数量、重复与不存在目标拒绝；保存失败不显示成功。
- 浏览器：真实延迟检查过程可见并递增、重载继续、终态展示；技能/插件添加编辑移除标签，取消无写入，筛选与搜索组合、无标签/空结果，插件更新入口定位；三语言、主题、窄屏和键盘。
- 交付时提供构建、自动测试和截图证据；不代填用户 UAT 通过，不自动发布本轮改动。

## 本轮执行结果（2026-09-15）

- TypeScript 检查与生产构建通过；源码归档、许可证和 UAT 实例的源码摘要一致。
- 后端全量 117/117 通过，其中新增 8 项覆盖标签持久化、包版本路径变化、同名副本隔离、更新整个包、非法请求、原子保存失败、真实 HTTP 进度、逐项/应用/终态和准备失败恢复。
- 现有 Playwright 回归 63/63 通过。随后修正了清空技能标签筛选、列表标签宽度、耗时单位、旧记录缺少总数的显示和批次状态徽标；最终构建的这些路径已用 Playwright CLI 定向验证。
- CLI 实测：中文浅色的技能标签增改删、输入后直接保存、插件标签与更新入口；英文真实延迟批次的中途进度、刷新恢复、读取失败重连及部分完成；日语深色 390px/720px 的长标签、取消无写入、重复/超长校验、筛选与搜索组合、空结果清空、Escape 关闭筛选和插件更新入口。上述窄屏无水平溢出，截图已人工查看。
- 旧批次无 total 时显示已处理数量，不显示虚构百分比或持续准备动画。故意缺失的测试来源会计为失败并形成“部分完成”，不会作为应用通过更新的证据。
- 隔离测试环境之外，候选服务在本机读取实际清单：66 个技能、4,153 个可发现插件条目，所有条目包含标签字段；扫描项目与请求项目一致。实际清单验证只读，没有添加标签或执行更新。

本机执行日志与摘要位于 `output/skilldock-progress-tags/`，截图和 CLI 检查脚本位于 `output/playwright/skilldock-progress-tags/`；这些是 Git ignored 的本机证据，不随插件分发。可重跑的后端测试在 `assets/app/tests/progress-tags.test.mjs`，浏览器专用临时数据服务在 `assets/app/tests/progress-tags-browser.mjs`。
