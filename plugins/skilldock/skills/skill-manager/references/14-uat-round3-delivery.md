## 工程设计与实现

正式启动仅构建 local 环境，不创建、读取或调度旧 sandbox 状态；既存演练目录保留，避免清理用户旧验收数据。定时器遍历实际启用环境，本机计划持久配置不迁移。生产对 sandbox 清单、正文及所有动作返回 403 MODE_DISABLED，不能降级成本机操作。

GET /api/session 新增 defaultMode：正式服务为 local，显式程序参数 enableTestSandbox === true 才允许内部夹具模式。浏览器先取得并验证 token 与 defaultMode，再请求清单；会话失败或字段异常时不发起清单或写请求。URL、localStorage、普通启动器和环境变量无演练启用入口。

E2E 使用两个临时 home/project/state 服务：一个显式夹具执行完整生命周期，另一个使用默认生产配置验证单一本机产品行为。开发测试不读写用户真实技能；旧切换用例替换为启动顺序、失败恢复与生产边界用例。
