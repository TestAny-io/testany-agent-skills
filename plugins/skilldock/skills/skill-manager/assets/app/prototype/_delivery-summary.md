**对 API Contract**：本次不提出新接口。复用 Skill/Plugin/Marketplace/Activity/UpdateItem 等既有契约；继续用安装 ID 和绝对路径区分同名技能，插件技能按包内路径选择。列表筛选、排序与原型分页都在内存，仅验证交互，不要求新增服务端分页。检查进度沿用现有能力，不能将 mock 计时移入生产。

## 2026-09-28 UAT 修订：下拉框主题

- **反馈**：深色下来源筛选出现浅色控件；用户要求一并检查其他下拉框。
- **取证**：Codex 内置浏览器中，来源控件计算样式为 `color-scheme: dark`，但文档为 `normal`。原型只给内容容器设置了配色模式，未将原生菜单的文档环境同步；来源与市场 select 还使用透明背景。
- **修改**：独立 `index.html` 增加原型专用文档类，显式同步 light/dark `color-scheme`；不修改正式应用文档。select、option、optgroup 统一主题色与禁用文字，来源/市场背景改为主题面板色，项目与来源补 WebKit appearance。外层统一焦点指示，保留键盘可见焦点。
- **全量检查**：来源（技能/插件）、项目、插件市场、检查频率、语言、原型状态下拉框，两主题共 14 个场景检查；包含 option 色值、项目禁用项、频率禁用、来源筛选后 4 项、英文切换后恢复中文、自定义间隔和系统主题变化。记录在 `output/dropdown-verification.json`、`output/dropdown-layout-verification.json`。
- **额外发现并关闭**：784px 下标签菜单左缘被主内容区裁剪。已改为换行工具栏内定位，1440/784/390px × 两主题均在可见区域内，保留已有 TagFilter 组件。
- **视觉证据**：已查看 `output/playwright/dropdown-source-{dark,light}-784.png`、`dropdown-tags-dark-784.png`、`dropdown-tags-dark-390.png` 及 `dropdown-{market,schedule,language}-dark.png`。菜单选项另核对计算色值；macOS 原生弹出菜单不包含在网页截图内，未将截图等同原生菜单逐像素验证。
- **工程验证**：原型类型检查与 Vite 构建退出 0；继续只修改原型目录，未接入真实业务或发布。
