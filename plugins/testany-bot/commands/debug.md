# Testany 故障诊断

分析 Testany 测试失败原因，排查问题根因。

## 使用方式

$ARGUMENTS

## 支持的操作

- **分析执行**：获取失败执行的详情
- **查看日志**：获取并分析执行日志
- **定位问题**：识别失败类型和原因
- **修复建议**：提供针对性的修复方向

## 安全边界

按 [debug 的安全日志流程](../skills/testany-debug/SKILL.md#签名日志请求安全边界) 解析请求。
不执行返回的 curlCommand，不用 eval/sh -c；默认可离线校验，真实日志读取须在当前授权内。
校验或下载失败报告日志未取得，不显示签名/认证值，不自动重跑测试。

## 示例

```
/debug Y2K-0601-00001
/debug 最近的执行为什么失败了
/debug 帮我看看日志
```
